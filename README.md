# `stats-using-cpp`

> A modern, minimal `C++` project for computing statistical parameters on `1D` and `2D` datasets.

---

## 🧪 About

`stats-using-cpp` is a modern C++ project for computing detailed statistical metrics on datasets, including mean, mode, variance, skewness, kurtosis, covariance, correlation and other statistical parameters.

---

## 📌 Features

- Compute basic statistics: **sum, mean, median, mode, range**.
- Advanced statistics: **population & sample variance, standard deviation**.
- Higher-order metrics: **central moments (k=0…5), skewness, kurtosis**.
- Dataset comparisons: **covariance & correlation coefficient**.
- Detect if dataset is sorted.
- Simple and extendable API using modern C++.

---

## ⚙️ Project Requirements

- **C++11 or later**
- **GCC / Clang / MSVC** compatible compiler
- Git (optional, for cloning)
- A terminal or shell environment (Bash, CMD, PowerShell)

## 🛠️ Project Setup

- #### Open the terminal and navigate to the location where you want to place the project

```bash
cd Desktop
```

- #### Clone the repository (Paste the following command)

```bash
git clone
```

- #### Navigate to the project directory

```bash
cd path/to/project
```

- #### To run the project type the following command

```bash
make
```

```bash
./main
```

- #### To run the `test` case file run the following command

```bash
  make test
```

```bash
./test
```

- ### After you are done with the project run the following command to clean the build artifacts

```bash
make clean
```
